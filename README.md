# Arendo

Веб-приложение для аренды помещений на определённый период: календарь занятости, категории с фото и ценой, отзывы, статусы аренды (Ожидает / Активно / Завершено / Отменено), информация об арендаторах, штрафы, чёрный список и рейтинг.

Стек: PostgreSQL · Node.js (NestJS) · React.

## Структура

```
db/                 SQL-скрипты (01 схема, 02 логика, 03 данные, 04 запросы) и автотесты
docs/tz/            Техническое задание
docs/db/            Описание БД, ER-диаграмма, статусы
docs/api/           openapi.yaml и список эндпоинтов
docs/checklists/    Чек-лист БД
docs/reports/       Отчёт руководителя
docs/qa/            Ответы на вопросы кафедры
```

## Запуск

Тесты БД (PostgreSQL-сервер не нужен, используется PGlite):

```bash
cd db/tests && npm i && npm test
```

На настоящем PostgreSQL 15+:

```bash
createdb arendo
psql arendo -f db/01_schema.sql -f db/02_logic.sql -f db/03_seed.sql
```
