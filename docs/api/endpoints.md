# Список API Arendo

Сгенерировано из [openapi.yaml](openapi.yaml) (всего эндпоинтов: 39). Базовый URL: `/api/v1`.

## Auth — Регистрация и вход

| Метод | Путь | Авторизация | Описание |
|---|---|---|---|
| `POST` | `/auth/register` | нет | Регистрация (роль tenant или owner) |
| `POST` | `/auth/login` | нет | Вход по email и паролю |
| `POST` | `/auth/refresh` | нет | Обновление access-токена (ротация refresh-токена) |
| `POST` | `/auth/logout` | JWT | Выход (отзыв refresh-токена) |
| `GET` | `/auth/me` | JWT | Текущий пользователь |

## Rooms — Помещения, фото, календарь

| Метод | Путь | Авторизация | Описание |
|---|---|---|---|
| `GET` | `/rooms` | нет | Каталог помещений с фильтрами |
| `POST` | `/rooms` | JWT | Создать помещение (owner) |
| `GET` | `/rooms/owned` | JWT | Собственные активные помещения владельца |
| `GET` | `/rooms/{id}` | нет | Карточка помещения (фото, цена, рейтинг) |
| `PATCH` | `/rooms/{id}` | JWT | Частично изменить помещение (его владелец) |
| `DELETE` | `/rooms/{id}` | JWT | Деактивировать помещение (не удаляется физически) |
| `POST` | `/rooms/{id}/photos` | JWT | Загрузить фото (multipart, jpeg/png/webp, до 5 МБ) |
| `DELETE` | `/rooms/{id}/photos/{photoId}` | JWT | Удалить фото |
| `GET` | `/rooms/{id}/calendar` | нет | Календарь занятости (занятые интервалы за период) |
| `GET` | `/rooms/{id}/blocks` | JWT | Будущие и текущие закрытия помещения (владелец, admin) |
| `POST` | `/rooms/{id}/blocks` | JWT | Закрыть помещение на период (ремонт, уборка) |
| `DELETE` | `/rooms/{id}/blocks/{blockId}` | JWT | Снять закрытие |

## Categories — Категории помещений

| Метод | Путь | Авторизация | Описание |
|---|---|---|---|
| `GET` | `/categories` | нет | Список категорий с фото и ориентировочной ценой |
| `POST` | `/categories` | JWT | Создать категорию (admin) |
| `PATCH` | `/categories/{id}` | JWT | Изменить категорию (admin) |
| `DELETE` | `/categories/{id}` | JWT | Удалить категорию (admin); нельзя, если есть помещения |

## Bookings — Аренды и статусы

| Метод | Путь | Авторизация | Описание |
|---|---|---|---|
| `GET` | `/bookings` | JWT | Мои аренды (арендатор) или аренды моих помещений (owner); admin — все |
| `POST` | `/bookings` | JWT | Арендовать помещение на период (tenant) |
| `GET` | `/bookings/{id}` | JWT | Аренда с историей статусов |
| `POST` | `/bookings/{id}/cancel` | JWT | Отменить аренду (завершённую отменить нельзя) |
| `POST` | `/bookings/{id}/complete` | JWT | Принять помещение и завершить аренду (owner, admin) |

## Reviews — Отзывы и рейтинг

| Метод | Путь | Авторизация | Описание |
|---|---|---|---|
| `GET` | `/rooms/{id}/reviews` | нет | Отзывы о помещении |
| `POST` | `/bookings/{id}/review` | JWT | Отзыв арендатора о помещении (только по завершённой аренде, один на аренду) |
| `POST` | `/bookings/{id}/tenant-review` | JWT | Оценка арендатора владельцем (формирует рейтинг клиента) |

## Tenants — Информация об арендаторах

| Метод | Путь | Авторизация | Описание |
|---|---|---|---|
| `GET` | `/tenants/{id}` | JWT | Карточка арендатора — статистика, рейтинг, просрочки, статус чёрного списка (owner, admin) |
| `GET` | `/tenants` | JWT | Арендаторы помещений владельца (admin — все) |

## Blacklist — Чёрный список и штрафы

| Метод | Путь | Авторизация | Описание |
|---|---|---|---|
| `GET` | `/blacklist` | JWT | Действующие записи чёрного списка (owner — свои, admin — все) |
| `POST` | `/blacklist` | JWT | Добавить арендатора (owner — в свой список, admin — глобально) |
| `DELETE` | `/blacklist/{id}` | JWT | Снять ограничение (запись помечается отозванной) |
| `GET` | `/penalties` | JWT | Штрафы (арендатор — свои, owner — по своим помещениям, admin — все) |
| `PATCH` | `/penalties/{id}` | JWT | Отметить штраф оплаченным или списанным (owner, admin) |

## Admin — Администрирование

| Метод | Путь | Авторизация | Описание |
|---|---|---|---|
| `GET` | `/health` | нет | Проверка живости сервера и соединения с БД |
| `GET` | `/admin/users` | JWT | Список пользователей (admin) |
| `PATCH` | `/admin/users/{id}/status` | JWT | Заблокировать / разблокировать пользователя (admin) |

## Коды ответов

| Код | Значение |
|---|---|
| 200/201/204 | успех |
| 401 | нет или просрочен токен |
| 403 | нет прав |
| 404 | не найдено |
| 409 | конфликт: занятое время, недопустимый переход статуса |
| 413 | файл слишком большой |
| 422 | ошибка проверки данных |
| 429 | превышен лимит запросов |
