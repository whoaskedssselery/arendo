Команда №5 «ЧЕКЛИ». Тестировщик: Панов В.О. Дата прогона: 27.11.2026.

## 1. Цель

Проверить, что после реализации функций ТЗ, кэширования и оптимизации приложение работает, и перечислить, что не проверено или не сделано.

## 5. Найденные и исправленные дефекты

| Дефект | Исправление |
|---|---|
| Разблокировка администратором не снимала автобан: аренда оставалась запрещена | при разблокировке отзываются глобальные баны |
| Демо-режим показывал «Категория добавлена», ничего не добавляя | демо принимает только чтение категорий |
| Блок отзывов перезапрашивался при каждом открытии карточки | отзывы кэшируются на клиенте |
| Фото из тестовых данных показывались битыми картинками | подставляется иллюстрация с пометкой |
| Заголовки безопасности Nginx не доходили до страниц | заголовки заданы в каждом разделе конфигурации |
| Проверка ширин не укладывалась в лимит времени в CI | увеличен лимит этого теста |
| Тест конфликта брони зависит от часового пояса машины | запускается с поясом машины (`timezoneId`); сам тест не исправлен |

## 6. Что работает

Регистрация, вход и роли; категории; помещения с редактированием, фото, закрытием периодов и снятием с публикации; каталог с фильтрами; календарь по часам; аренда и статусы; история статусов; штрафы; отзывы о помещениях и оценки арендаторов; карточка арендатора; чёрный список; администрирование; светлая и тёмная темы.

## 7. Что не проверено и ограничения

* Нагрузка 500 одновременных пользователей и доступность 99 % за месяц не проверялись.
* Safari и Firefox не проверялись, только Chromium.
* HTTPS и реальный сервер с доменом не настраивались, CDN только описан.
* Отдельный инструмент миграций не подключён: изменения схемы — это пронумерованные SQL-скрипты.
* Демо-режим интерфейса не сохраняет данные и не поддерживает новые функции управления.

## 8. Как повторить

```bash
cd db/tests && npm ci && npm test
```

```bash
docker compose up -d --build --wait
```

Интеграционные тесты API и интерфейса: переменные `TEST_DATABASE_URL` и `LIVE_API`, порядок описан в начале файлов тестов и в `docs/frontend/README.md`.
