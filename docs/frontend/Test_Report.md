# Проверки frontend Arendo

> Прогон на этапе первой версии интерфейса. Актуальные результаты — в [docs/Test_Report.md](../Test_Report.md).

Дата: 27 ноября 2026. Среда: Linux Ubuntu 24.04, Node.js 24.22, Chromium (Playwright), PostgreSQL 16.15. Для живых тестов использовалась отдельная `arendo_frontend_test`, backend NestJS и production-сборка Vite через `vite preview`. Все перечисленные проверки выполнены, а не запланированы.

Браузерные наборы: **7 demo/UI-тестов + 4 production/live-теста**, оба набора без падений в итоговом запуске. Один тест объединяет несколько связанных проверок; строки таблицы не являются количеством отдельных тестов.

Исправлены в ходе работы: отсутствие маршрутов списков и кабинетов на backend; отправка пустого необязательного телефона; доступные названия select; политика отмены для владельца; разметка начала недели календаря; незаметная подмена отсутствующих фото; восстановление поискового поля из URL; пагинация приватных списков. Повторные тесты прошли после исправлений.

Границы проверки: Chromium, локальная сеть и локальная БД. Реальный CDN, удалённое развёртывание, Nginx в контейнере, Safari/Firefox и нагрузочное тестирование frontend здесь не запускались. Конфигурация Nginx и инструкция CDN подготовлены. Согласование макетов ожидает тимлида. Невыполненные пункты полного ТЗ вне перечисленных frontend issues описаны в README и не выдаются за готовые.
